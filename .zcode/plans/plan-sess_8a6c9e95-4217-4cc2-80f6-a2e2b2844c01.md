# 修复计划：核心修复包（分支 fix/analysis-fixes）

基于三路深度分析（核心聊天链路 / 并发背压 / 工具与基础设施，共约 40 项发现）并逐项亲自验证后，本次在新分支 `fix/analysis-fixes`（从 `feat/llm-runtime-backpressure` 切出）上实施以下 11 项修复，每项附回归测试。

## A. 已验证的高价值 Bug（8 项）

**1. 「重置我的」命令失效（键类型不匹配 + `__contains__` 恒真）**
- `__init__.py:817`：reset 命令用裸 `event.user_id`（int），而写入侧 `moe_llm.py:55` 用 `event_user_id(event)`（str）→ 永远清不到真实历史。改用 `event_user_id(event)`。
- `state_store.py`：`BoundedDequeStore`/`BoundedValueStore` 的 `__getitem__` 缺省创建且从不抛 KeyError，导致 `MutableMapping.__contains__` 恒为 True 并制造垃圾条目。两个类各覆写 `__contains__` 直接查 `self._values`。

**2. SSE 流式解析把非 `data:` 行喂给 `json.loads`（llm_api.py:217-233）**
- `elif line.startswith(b"")` 恒真 → `event:`/`retry:` 行和无空格 `data:[DONE]` 都会触发 ValueError → 整轮请求重试 → 群里已发出的分段内容被重复发送。
- 修复：只解析 `data:` 前缀行，其余行 continue；DONE 判断放宽（strip 后比较）。将单行解析抽成 `_parse_sse_data_line()` 纯函数便于测试。

**3. 工具总结兜底请求无异常保护（moe_llm.py:529-532）**
- summary 调用在重试循环之外且无 try，网络抖动会穿透到 matcher，用户得到空回复且不落历史。包 try/except，失败走已有的 `_build_empty_tool_summary_fallback()`。

**4. `except asyncio.CancelledError` 中 `matcher.finish` 吞掉取消（chat_runtime.py:256-262）**
- FinishedException 替换了 CancelledError，违反取消契约（上层取消语义、settle 任务误判）。改为：释放冷却 → try 一次性 `matcher.send` 终止提示 → `raise` 重新抛出。

**5. Python 3.10 下 TimeoutError 身份分裂（compat.py:33 vs moe_llm.py:2）**
- compat 层抛内建 `TimeoutError`，`moe_llm.py` 捕获 `asyncio.TimeoutError`（3.10 上是两个类）→ 超时走错分支：无友好文案、遥测记 FAILED、重试行为不同。
- 修复：`compat.py` 导出统一别名，全项目统一 `from .compat import TimeoutError`（moe_llm.py 及其他引用点）。

**6. member_cache 把故障降级名（裸 QQ 号）缓存整个 TTL（member_cache.py:56-68）**
- 一次瞬时故障让成员显示裸 QQ 号 600 秒。fetch 失败（外层异常或 `_fetch` 内部降级）时不写缓存，下次直接重试。

**7. 重试通知发送在 try 块外（moe_llm.py:390-397）**
- `bot.send("api又卡了呐...")` 失败会中断已执行到一半的整轮请求并跳过持久化。通知发送自身包 try/except（失败仅记日志）。

**8. `format_message` 剥掉任何 "ai" 开头文本的前两个字符（utils.py:318-319）**
- "airpods 怎么样" → "rpods 怎么样" 进 LLM。改为仅当 `plain == "ai"` 或 `plain.startswith("ai ")`（不区分大小写）时剥离唤醒词。

## B. 安全加固（3 项）

**9. Tavily 搜索禁用 TLS 校验（search.py:69）**
- 全仓库唯一 `ssl=False`，且请求带 `Authorization` API key，搜索结果还拼进对话上下文。移除该参数恢复证书校验。

**10. `search_api` 占位符原样发出（config.py:67 + search.py:58）**
- 默认值 `"your api"` 未配置时每次搜索都向第三方发无效凭据。在 `get_search` 入口检测占位/空值 → 返回友好提示不发起请求，并记 warning。

**11. 配置布尔校验补全（config.py:204-217）**
- `generated_tools_enabled`/`fastai_enabled`/`emotions_enabled`/`private_chat_enabled`/`show_datetime`/`runtime_watch_enabled` 等遗漏项传入字符串 `"false"` 时恒为真值，功能关不掉。并入布尔校验列表；未知配置键从静默忽略改为 warning 日志（不做硬拒绝，避免破坏存量部署）。
