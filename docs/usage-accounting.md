# GLM与模型用量统计

BigModel配置只启用`glm-5.3-flash`，密钥引用宿主`glm_api_key`，不落入模型配置。模型支持图片、视频、文件和工具；`thinking`强制enabled、clear_thinking=false，reasoning_effort=max，temperature=1，top_p=.95；流式请求同时设置tool_stream。现有工具执行器使用非流式工具调用。

`priority_consume=true`优先消耗此模型，覆盖分类、三档MoE、识图、资料分析与群聊总结；其他服务商的模型池与备用链保留。GLM思考不可关闭，输出预算最低8192，避免分类预算只生成思考而没有答案。

模型配置`usage_token_budget=20000000`首次建立额度周期。输入+输出达到额度后，路由标记耗尽并改选备用模型，模型仍保留。缓存、推理是子集，不重复累计。准入时为并发请求预留文字/工具输入字节上界和输出预算；音视频等按完整上下文预留。剩余额度已被进行中的任务预留时暂用备用模型，不把限流误记为耗尽，不让普通对话排队等待视频。接近耗尽时仅允许最后一个任务，它的实际响应可能跨过阈值，此后不再发起请求。启动、刷新模型、恢复上游额度标记均不会自行重置本地额度。超级管理员确认补充后执行：

```
补充模型额度 glm-5.3-flash (bigmodel) 20000000
```

新的额度周期以当时累计用量为基线，保存操作者与时间，保留全部历史。上游402/403额度错误仍受原来的停用与备用机制约束。

## 持久记录

插件配置目录`usage/usage.sqlite3`保存每次传输尝试：bot、群、QQ、场景、请求ID、用途、服务商、模型、输入、输出、缓存、推理、上游返回的其他数字用量、状态、币种与估价及价格快照。分类、普通对话、工具后的继续回答、流式、多模态、TokenHub向量/其他能力均进入账本。恢复重启任务使用已保存的用户和群身份。失败、取消、上游缺失usage明确记为未知，不推测为免费。无个人上下文的系统调用标为unattributed，不归给用户。无提示词、附件、API密钥或响应正文。

流式同一个HTTP请求更新同一行，累计usage快照重复返回不重复计数。SQLite只在工作线程访问，事务提交后返回，重启不丢已提交的记录。独立于Agent运行轨迹的PostgreSQL表，无QWeb Schema迁移。

记录从部署本功能开始。旧版已丢弃的50条之外的内存历史不能追溯恢复；完整历史指账本中已保存的全部记录。导出使用分页游标读取所有记录，不受查询50条/5000条限制。

## 管理指令

均仅超级管理员可调用，支持现有命令前缀：

```
查看消耗 10
模型用量统计 周
模型用量统计 月 群 123456 用户 12345
模型用量图 年
模型用量图 周 用户 12345
导出模型用量 全部
导出模型用量 全部 群 123456 用户 12345
刷新模型价格
设置模型估价 <模型编号或完整名称> <输入价> <输出价> <缓存价> USD
```

周/月/年分别为近7/30/365天，UTC时间。图表按模型统计Token占比，同一个模型跨平台合计；明细列出模型、平台、调用次数、Token与百分比，曲线按模型分色。占比和曲线显示前六个模型及其余模型合计，表格显示前18个模型；全部明细可导出。只有一个模型时明确显示该模型100%，不会生成虚构的其他模型用量。可同时按群、用户、真实模型ID筛选；带空格的模型名需加引号。统计图可选依赖`[statistics]`，文字和CSV无绘图依赖。CSV含稳定请求ID、作用域及价格快照，为后续个人计费提供依据；当前不会扣款。导出文件权限0600，24小时后在下次导出时清理。

NewAPI本地价格来自`moellm_newapi_prices_file`私有快照，包含传统ModelRatio/CompletionRatio/CacheRatio/CreateCacheRatio及新版`billing_setting.billing_mode`、`billing_setting.billing_expr`。只读提取站点options后再执行“刷新模型价格”。传统输入价格按`ModelRatio * 1000000 / QuotaPerUnit`折算，默认QuotaPerUnit=500000；表达式中的价格已经是USD/百万Token，不能再乘2。

`moellm_newapi_prices_url`可配置额外的NewAPI参考价格源，例如`https://basellm.github.io/llm-metadata/api/newapi/ratio_config-v1-base.json`。“刷新模型价格”会拉取该地址并原子保存私有快照，启动仅加载快照，不等待远端网络；拉取失败继续使用缓存。本地站点自定义规则优先于公开参考价格，管理员手动价格优先于两者。精确模型名优先；仅在没有精确匹配时允许大小写或唯一的服务商前缀匹配，不把不同版本当成同一模型。

表达式仅解析线性Token价格及`len <= N`上下文阶梯，不执行远程表达式代码。阶梯使用完整输入长度判断，缓存命中不会错误降低档位。图片/音频独立价格、请求参数条件和按次计价等暂不能从当前账本可靠计算的规则保持未估价；显式本地未知规则不会回落为公开的另一套价格。管理员可为缺价模型设置独立参考价格。

已有记录中的价格快照和估价不因后续改价变化。历史缺价记录会在报表中按当前参考价格补估并明确标注，账本原始行不回写；CSV的`reference_estimate`、`reference_currency`和`reference_price_snapshot`独立保存这部分参考估算。

估价按站点默认倍率1的参考资源成本显示，不等于免费额度实际支出或未来个人扣款；USD与CNY分开合计。未来正式收费需另做权益、费率版本、结算和退款流程。
