# Protocol inventory attribution

The generated files in this directory contain normalized action names,
summaries, and request schemas derived from these pinned MIT-licensed sources:

- OneBot v11, commit `d4456ee706f9ada9c2dfde56a2bcfc69752600e4`.
- OneBot v12 draft, commit `d533f0fca3bd14781d4461776dba8d907d9de253`.
- NoneBot Adapter OneBot 2.4.6, commit
  `3ac943fc4470d851219f368cacadf3dcdd649ee7` (compatibility reference).
- NapCatDocs 4.18.19, commit
  `14ad6896579abf17c761cdf8d9dfb7c3ea396305`; authoritative input file
  `src/api/4.18.19/openapi.json`, SHA-256
  `905ff1faa265cdfa6401a91e8ed832ab15c9e32a7683c42dc11bb6752682ae39`.

The upstream source code is not vendored. `actions.json` is deterministic
technical data; `policies.json` is a separate, project-maintained security
review and is not supplied by those upstream projects.
